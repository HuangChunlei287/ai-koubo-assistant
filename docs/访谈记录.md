# 用户访谈记录（2026-11-25）

## 访谈概况

- **方式**：微信文字访谈（非录音）
- **人数**：3 人
- **对象**：有真实短视频创作经历的创作者
- **匿名处理**：U1 / U2 / U3
- **限制**：便利样本，文字回答，未做语音追问；结论只代表这 3 人，不外推为全体创作者

---

## U1：小吃街探店口播（抖音）

**最近一次创作**：上周六，逛小吃街时随手口播，讲几家好吃的小店，发在抖音。

**实际流程**：

1. 先想好要说哪几家
2. 在备忘录记几个店名
3. 琢磨怎么说不生硬
4. 出门前试顺一遍
5. 到地方直接开拍

**最耗时/最烦**：纠结怎么介绍味道，总觉得自己说得平平无奇，改来改去挺烦。

**文案习惯**：像和朋友聊天那样写，句子短一点，不用花哨；一般改两遍；最纠结开头，怕开口太普通，别人直接划走。

**分镜习惯**：不会认真写分镜，心里大概清楚——先对着镜头打招呼，再切食物特写。拍的时候经常卡：要么忘了下一家要讲啥，要么一句话说得别扭。

**最想要的功能**：**脚本优先**。镜头自己随便拍就行，台词最难捋；有脚本打底，不用自己绞尽脑汁想怎么说。

**原话摘录**：

> “最耗时间的是纠结怎么介绍味道，总说得平平无奇，改来改去挺烦。”
>
> “最纠结开头，怕开口太普通，别人直接划走。”
>
> “优先要脚本。镜头我自己随便拍就行，台词最难捋。”

---

## U2：文创店探店（小红书）

**最近一次创作**：大概十天前，拍了一个新开的文创店探店，发在小红书。

**实际流程**：

1. 先搜这家店有什么特色
2. 列几个看点，搭好顺序
3. 写完稿子默读几遍
4. 再去现场拍

**最耗时/最烦**：删减内容。想讲的小东西太多，视频不能太长，反复取舍很磨人。

**文案习惯**：结构是“进门感受 → 有意思的物件 → 简单总结”，口语化写；大概改两到三遍；最纠结中间的亮点部分，怕讲得没意思、吸引不到人。

**分镜习惯**：会写一个很简单的提纲，标注哪里拍店内环境、哪里拍摆件。拍的时候容易卡在描述细节——东西好看，但不知道怎么形容。

**最想要的功能**：**重点词**。大概内容能写出来，但录的时候容易啰嗦；有重点词提醒，能抓住核心，不会越说越偏。

**原话摘录**：

> “最麻烦的是删减内容，想讲的小东西太多，视频不能太长，反复取舍很磨人。”
>
> “最纠结中间的亮点部分，怕讲得没意思，吸引不到人。”
>
> “想要重点词。录的时候容易啰嗦，有重点词提醒，能抓住核心，不会越说越偏。”

---

## U3：傍晚散步随拍（抖音）

**最近一次创作**：一个多月前，傍晚散步时随拍，随口聊了聊最近喜欢的歌，发在抖音。

**实际流程**：

1. 想到主题
2. 不写完整稿子，只记几个关键词
3. 到地方直接开拍
4. 不好就重录

**最耗时/最烦**：状态不对。有时候情绪平平，录好多遍都没有感觉。

**文案习惯**：基本没有正式文案，大多是边拍边说；拍完如果要配字幕，稍微顺一下语句，很少反复修改；比较纠结结尾——不知道怎么自然收住，不生硬。

**分镜习惯**：完全不规划镜头，走到哪拍到哪，没有分镜。经常卡壳：说着说着突然不知道该聊什么，冷场。

**最想要的功能**：**分镜**。拍出来总是一个镜头拍到底，画面很单调；有分镜参考，就知道什么时候换角度、切画面，视频会丰富一点。

**原话摘录**：

> “最烦的是状态不对，有时候情绪平平，录好多遍都没有感觉。”
>
> “完全不规划镜头，走到哪拍到哪，没有分镜。经常卡壳，说着说着突然不知道该聊什么，冷场。”
>
> “优先分镜。我拍出来总是一个镜头拍到底，画面很单调。”

## 横向对比

| 维度 | U1 | U2 | U3 |
|---|---|---|---|
| 平台 | 抖音 | 小红书 | 抖音 |
| 内容类型 | 小吃街探店 | 文创店探店 | 散步随拍 / 聊歌 |
| 脚本 | 备忘录 + 改 2 遍 | 搜特色 + 列看点 + 改 2–3 遍 | 不写完整稿，只记关键词 |
| 最耗时 | 描述味道 | 删减内容 / 取舍 | 状态 / 情绪 |
| 分镜 | 心里大概清楚 | 简单提纲，标环境/摆件 | 完全不规划 |
| 最想要 | 脚本 | 重点词 | 分镜 |
| 常见卡点 | 开头、忘词 | 中间亮点、描述细节、啰嗦 | 结尾、冷场、画面单调 |

## 关键发现

1. **脚本是共同基础**：三个人都绕不开“把想法变成能说出口的话”，只是卡点不同——U1 卡开头和味道描述，U2 卡内容取舍和亮点，U3 卡结尾和现场表达。
2. **重点词解决“啰嗦/跑偏”**：U2 能写大概内容，但录制时容易越说越偏，需要关键词提醒；这和产品的「字幕重点词」功能直接对应。
3. **分镜解决“一镜到底/冷场”**：U3 不写脚本、不规划镜头，最需要的是“什么时候换角度、切画面”；这和产品的「拍摄分镜」直接对应。
4. **不存在统一的“最想要”**：U1 要脚本、U2 要重点词、U3 要分镜。产品不应该只做一个功能，而应该让不同卡点的人从不同入口进入。
5. **拍摄现场的真实问题**：忘词、别扭、冷场、画面单调——这些不是“文案好不好”能完全解决的，所以提词器 / 重点词 / 分镜提示有实际价值。

## 对产品的启示

- **入口应该分模式**：没脚本 → 生成脚本；有脚本 → 拆分镜；只想要提醒 → 重点词/提词器。
- **脚本必须可编辑**：U1/U2 都会自己改稿，不会直接照念 AI 文案。
- **重点词要短、要能扫一眼**：不是长句总结，而是价格、卖点、行动词。
- **分镜建议要说人话**：U3 不需要专业运镜术语，只需要“什么时候换角度、切什么画面”。
- **设备假设要保守**：三个人都是单人、手机拍摄，不应默认有团队、灯光、稳定器。
