# 1–2 分钟演示录屏脚本

> 目标：让面试官在 2 分钟内看懂「用户问题 → 产品流程 → 真实可用 → 你的改造」。
> 要求：录屏前关掉浏览器翻译；用新会话；不要露出 API Key；分辨率 1080p；语速正常。

## 录制前准备

- [ ] 运行 `npm run dev`，确认 http://localhost:3000 正常
- [ ] 设置页确认 DeepSeek Key 已配置（录屏时不要点开 Key 输入框）
- [ ] 关闭 localhost 的浏览器自动翻译（否则页面会崩）
- [ ] 新建一个会话，清空旧结果
- [ ] 准备一个真实主题，例如：`冬天火锅店双人餐 199 元`
- [ ] 准备好要展示的分镜和发布文案结果，避免录制时等待太久

## 分镜脚本

### 0:00–0:15 开场

画面：首页全貌

口播：
> 这是一个面向中文短视频创作者的口播创作助手。它解决的不是剪辑，而是开拍前最耗时的准备：写脚本、拆镜头、做字幕重点词。

### 0:15–0:40 输入创作需求

操作：在左侧填写主题、平台、受众、时长、风格，点「生成口播脚本」

口播：
> 用户不需要先写文案，只要给一个主题，再选平台、受众、时长和风格。AI 会先写一版可以直接念的口播脚本。

画面：脚本出现在下方输入框

口播：
> 注意，脚本不是直接变成分镜，而是先回到可编辑的输入框。用户可以改，改完再提交。

### 0:40–1:00 生成分镜

操作：点「提交」，等待结果，滚动展示分镜卡片

口播：
> 提交后，模型会把脚本按语义拆成镜头，每个镜头给出景别、机位、构图、氛围、台词、字幕和 1 到 3 个需要强调的重点词。

画面：展开一个「拍摄提示」，指出中文拍摄建议

口播：
> 这些不是给 AI 视频模型的英文 prompt，而是给真人拍摄看的中文执行提示。

### 1:00–1:20 发布文案

操作：点「生成发布文案」，展示标题、封面短句、描述

口播：
> 分镜确认后，还能生成标题、封面短句和平台描述，直接复制给运营或自己发布用。

### 1:20–1:40 技术说明

画面：切到 README 或代码目录（可选）

口播：
> 项目基于 MIT 开源的 Script2Video 二次开发。原项目是英文的「剧本到 AI 视频分镜」工具，我把它改成了中文口播场景：新增主题生成脚本、重写分镜提示词、加字幕重点词和发布文案，并接入了国内可直连的 DeepSeek。过程中还处理了 DeepSeek 不遵守 JSON 嵌套结构的问题。

### 1:40–2:00 限制与下一步

画面：回到首页

口播：
> 目前是本地单用户 Demo，不做视频渲染，分镜也还不能逐字段编辑。下一步会先用真实用户测试验证「脚本和分镜哪个更有价值」，再决定优先做多平台语气还是分镜编辑。

## 录制后检查

- [ ] 视频长度 1–2 分钟
- [ ] 没有 API Key、手机号、真实姓名
- [ ] 全程没有报错、没有浏览器翻译浮层
- [ ] 字幕/口播与画面对得上
- [ ] 导出的 mp4 能正常播放
