# 用户访谈提纲（3–5 人）

> 目标：验证「口播视频准备阶段最耗时的环节」和「AI 脚本/分镜是否有用」，不是推销产品。
> 原则：问真实经历，不问假设；不诱导；不编造；录音前征得同意。

## 招募条件

优先找最近 3 个月**真实拍过**短视频的人：

- 探店 / 美食 / 本地生活
- 种草 / 好物分享
- 知识分享 / 口播讲解
- 门店商家或运营

至少 3 人，最多 5 人；新手和有经验的都找 1–2 个。

## 访谈前说明（1 分钟）

- 我是计算机专业学生，在做课程/实习作品，想了解真实创作流程
- 没有标准答案，聊最近一次真实经历就好
- 不会收集账号密码等敏感信息；录音只用于整理笔记，可随时停止
- 访谈约 20–30 分钟

## 问题清单

### A. 最近一次真实创作（10 分钟）

1. 你最近一次拍口播短视频是什么时候？拍的是什么内容？
2. 从「决定要拍」到「按下录制」，你实际做了哪些步骤？
3. 每一步大概花了多久？哪一步最烦、最想跳过？
4. 那条视频最后发在哪个平台？为什么选这个平台？

### B. 脚本与分镜（10 分钟）

5. 口播文案一般怎么写？用备忘录、文档、还是直接对着镜头说？
6. 写完会改几遍？改的时候最纠结什么（开头、卖点、结尾）？
7. 拍之前会不会想「每个镜头拍什么」？会写下来吗？写在哪？
8. 拍摄时最常出现的问题是什么（忘词、镜头不知道怎么切、光线/背景乱）？
9. 字幕一般怎么做？会标重点词吗？怎么决定标哪些词？

### C. 现有工具与替代方案（5 分钟）

10. 现在用过哪些工具帮忙写文案/提词/做字幕？哪些好用，哪些放弃了？
11. 有没有试过用 AI 写脚本？效果如何？为什么没继续用？
12. 如果有一个工具能从主题直接给出「脚本 + 分镜 + 重点词」，你最想先看哪个结果？

### D. 价值与顾虑（5 分钟）

13. 这样一套流程，你估计能帮你省多少时间？
14. 你最担心 AI 生成的内容哪里不靠谱？（事实、语气、卖点、版权）
15. 如果只能保留一个功能，你选脚本、分镜、字幕重点词，还是发布文案？为什么？

### E. 收尾

16. 我做完 Demo 后，你愿意花 10 分钟试一下并给反馈吗？
17. 有没有你认识的其他创作者，适合我也聊一下？

## 记录模板

| 字段 | 内容 |
|---|---|
| 受访者编号 | U1 |
| 创作类型 / 平台 | 探店 / 抖音 |
| 经验 | 拍过 20 条，自己写自己拍 |
| 最近一次流程 | 想主题 → 备忘录写文案 → 直接拍 → 剪映字幕 |
| 最耗时环节 | 写开头钩子 + 拆镜头 |
| 现有工具 | 备忘录、剪映、ChatGPT |
| 对 AI 的顾虑 | 怕编造价格和卖点 |
| 最想保留的功能 | 分镜 |
| 原话摘录 | “……”（至少 2 句） |
| 访谈日期 / 时长 | 2026-11-XX / 25 分钟 |

## 分析方式

- 先按「最耗时环节」聚类，统计出现次数
- 再把痛点映射到功能：脚本 / 分镜 / 字幕 / 发布文案
- 只把**至少 2 人提到**的问题列为 P0；单人提到的放入观察列表
- 访谈记录原话与结论分开写，不能把推测写成用户原话

## 禁止事项

- 不引导用户说“这个功能很好”
- 不把没做过的访谈写成已做
- 不虚构人数、原话、使用时长
- 不在未征得同意时录音或公开受访者信息
