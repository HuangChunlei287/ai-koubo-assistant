## 补充：异常场景清单

- 模型超时（>60 秒）
- 模型返回空内容
- 模型返回 markdown 包裹的 JSON
- 模型返回字段缺失 / 序号为 0 / dialogue 为字符串
- 浏览器自动翻译导致 React hydration 报错（已记录，规避方式：关闭该站点翻译）
- 本地磁盘满 / node_modules 损坏
